03

Reliability is part of the scope

Handle errors visibly

Route execution failures to an owner with enough context to investigate. n8n supports error workflows; the alert still needs a response process and a recovery decision.

Make retries safe

Identify repeated events and use a stable record identifier where the destination supports it. Check whether a failed request actually wrote the record before retrying an action with side effects.

Respect API and data limits

Map authentication, supported operations, pagination and rate limits. Keep only the execution data needed for diagnosis, with an agreed retention period. A connector does not prove that every required operation is available.

Keep credentials under control

Use accounts owned by the appropriate team, limit permissions and document rotation. An exported workflow should not become a second store of live credentials.

Agree a recovery path

Document how to stop the workflow, locate a failed execution and decide what can safely be replayed. Test recovery with sample records before switching on live processing.

Example: a form-to-CRM workflow

Illustrative acceptance plan. Scope the workflow export and version-specific test results as part of the implementation.

Validate and identify

A webhook receives a sample enquiry. Validate required fields, normalize the data and check its event identifier before attempting a CRM write.

Write and confirm

Create or update the agreed record, then check the destination response and record identifier. Notify the team only when the required write has succeeded.

Test the exceptions

Replay the same sample, omit a required field and simulate a CRM timeout. The expected outcomes are one record for the duplicate, a clear validation rejection and an actionable failure for the timeout.

FAQ

Questions before we start

What does an n8n consultant help with?

Workflow design, integration, an existing-instance review, migration planning, failure handling and team handoff. The scope should identify both the business outcome and who will operate the workflow.

Is self-hosted n8n free to operate?

The Community edition is available without a paid license key, but hosting, backups, maintenance and connected APIs still have costs. Other editions and n8n Cloud have their own plans and limits. Compare the current vendor terms and your operating needs before choosing.

Will moving from Zapier or Make save money?

It depends on execution volume, workflow complexity, required features and the time spent maintaining the system. Compare subscription charges with hosting, implementation, monitoring and maintenance. A migration does not carry a fixed savings or zero-downtime guarantee.

Does self-hosting keep all data on my server?

Not necessarily. Hosting controls where n8n runs, while connected services and model APIs may receive data during execution. Review each integration, execution-log retention, access permissions and backups before handling sensitive records.

How do you test failure recovery?

Agree tests for malformed input, duplicate events, expired credentials, rate limits and downstream timeouts. Check both the alert and the destination record. Retrying a step should not silently create a second customer, invoice or message.

Can my team maintain the workflows?

The handoff can include workflow exports, configuration notes, credential ownership and an operating runbook. Visual workflows still require familiarity with their data and integrations. Custom-code steps need an appropriate technical owner.

How long does a build or migration take?

The timeline follows the number of workflows, access dependencies, data quality and the acceptance tests. We scope a first workflow before committing to a wider rollout. Migration planning also needs a cutover and rollback window.
