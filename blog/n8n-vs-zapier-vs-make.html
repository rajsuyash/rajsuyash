n8n vs Zapier vs Make: Which Automation Platform Is Best in 2026?

n8n is the cheapest at volume and the best fit for complex or AI workflows. Zapier has the most apps (9,000+) and the easiest setup. Make is the visual middle, from $9/month for 10,000 credits. Pick by workflow size: many steps favour n8n, quick two-app links favour Zapier, a visual builder on a small budget favours Make.

Updated November 2026: I re-read the pricing pages of n8n, Zapier and Make on 17 November 2026 and corrected this page against them. The biggest fix is Make: it still sells Core, Pro and Teams plans, and its $9 tier is 10,000 credits, not 5,000. Zapier's app count is 9,000+, not 10,000+. I did not build or run workflows on any of the three platforms for this update. The cost comparison below is a calculation from published prices, and the assumptions are stated next to it.

n8n: The Developer's Choice

n8n is a workflow automation tool popular with developers and any business that wants control over where its automations run.

Strengths

  • Self-hosting option. Run the Community Edition on your own server. There is no execution fee, and your data stays on your infrastructure.
  • Code in the workflow. JavaScript and Python code steps and a generic HTTP Request node are included on every plan, which matters for AI automation, data transformation and APIs without a ready-made node.
  • Billing by whole run. n8n counts one execution per workflow run, "regardless of complexity" (n8n pricing page), so a 20-step workflow costs the same as a 2-step one.
  • AI-native building blocks. The pricing page lists an AI Agent node, an MCP Server Trigger and an MCP Client on every plan, so you can build AI agents that call tools inside one workflow.

Weaknesses

  • Smaller app library. 2,000+ integrations against Zapier's 9,000+. For anything less common you fall back to the HTTP Request node, which works but takes more setup.
  • Steeper learning curve. It rewards technical users. A team with no coding experience will take longer to get going.
  • Self-hosting is your job. Updates, backups and uptime are yours. n8n Cloud removes that, at a price.

Pricing (read 17 November 2026)

  • Community Edition (self-hosted): free. You pay only for the server. The Docker self-hosting guide walks through the setup.
  • Cloud Starter: €20/month billed annually, 2,500 workflow executions, 5 concurrent executions, 1 shared project.
  • Cloud Pro: €50/month billed annually, 10,000 executions, 3 shared projects, up to 50 concurrent executions, and search of executions by the data they contain.
  • Business: €667/month billed annually for 40,000 executions. The pricing page marks it self-hosted only, and it adds SSO and LDAP, Git version control, queue mode and 6 shared projects.
  • Enterprise: custom pricing, hosted by n8n or self-hosted, with audit logging, log streaming, an external secret store and 200+ concurrent executions.

The euro prices are the annual-billing rates shown on the page. I did not read the monthly-billing toggle, so I give no monthly-billed figure for n8n.

Zapier: The Easy Button

Zapier pioneered the "if this, then that" approach to connecting apps and remains the easiest platform to start with.

Strengths

  • The largest app library. 9,000+ apps, per Zapier's own pricing page. If an app exists, Zapier probably connects to it, and that is its biggest advantage.
  • Fast setup. Non-technical users can build a working Zap in minutes. The trigger and action model is easy to follow.
  • Managed reliability. Uptime, scaling and error monitoring are Zapier's problem. Paid plans include automatic replay of errored tasks, which the Free plan does not.
  • More than Zaps. Zapier also sells Tables, Forms, Agents, Chatbots and an MCP server, which extend what a Zapier-only team can build.

Weaknesses

  • Cost tracks step count. Zapier bills per task, and its pricing page says every step in a Zap uses tasks, so a workflow with more steps costs more per run. The 10,000-task Professional tier is $129/month billed annually and $193.50 billed monthly.
  • Slower polling on cheaper plans. Zapier's plan data lists 15-minute polling on Free, 2-minute on Professional and 1-minute on Team.
  • Free is very small. 100 tasks a month and two-step Zaps only. Branching and premium apps start on Professional.
  • No self-hosting. Your data runs through Zapier's servers. For regulated work or strict data-residency rules, that can end the discussion.

Pricing (read 17 November 2026)

Zapier's paid ladder is Professional, Team and Enterprise, and every tier is priced by task volume. Monthly-billed prices are 50% higher than the annual rates shown first:

  • Free: 100 tasks/month, two-step Zaps.
  • Professional: from $19.99/month annual ($29.99 monthly) for 750 tasks. 2,000 tasks costs $49 annual ($73.50 monthly); 10,000 tasks costs $129 annual ($193.50 monthly).
  • Team: from $69/month annual ($103.50 monthly) for 2,000 tasks, adding shared workspaces and a 1-minute polling interval.
  • Enterprise: custom pricing, not purchasable online.

Make (formerly Integromat): The Middle Ground

Make sits between Zapier's simplicity and n8n's power: a visual, drag-and-drop builder with more flexibility than Zapier at a lower price per step.

Strengths

  • Visual workflow builder. The canvas shows the whole scenario as a map, which helps when scenarios get complex.
  • Low entry price. Core is $9/month for 10,000 credits, and most actions use one credit. Units differ across vendors, so see the cost section before comparing headline prices.
  • A wide app list. 3,500+ apps, per Make's pricing page, which covers most popular tools.
  • Scheduling to the minute on paid plans. Free runs at a 15-minute minimum interval; Core adds scheduling down to the minute.

Weaknesses

  • Credit counting takes care. Make's FAQ says most actions consume one credit while some advanced features, such as its AI Provider, can use more. Estimate from the credits your scenarios actually consume.
  • No self-hosting. Like Zapier, Make is cloud-only.
  • Less code freedom than n8n. HTTP modules work on every plan, but n8n's JavaScript and Python code steps are a closer fit for heavy data work.
  • Steeper than Zapier. The canvas is powerful but takes longer to learn than Zapier's linear editor.

Pricing (read 17 November 2026)

Make moved from operations to credits as its billing unit in 2025 (its pricing FAQ says "As of August 27, credits are the billing unit"). It still sells separate tiers:

  • Free: 1,000 credits/month, 15-minute minimum interval between runs.
  • Core: $9/month for 10,000 credits ($0.90 per 1,000 credits), unlimited active scenarios, scheduling down to the minute.
  • Pro: $16/month at the 10,000-credit tier ($1.60 per 1,000), adding priority scenario execution, custom variables and full-text execution log search.
  • Teams: $29/month at the 10,000-credit tier ($2.90 per 1,000), adding team roles and shared scenario templates.
  • Enterprise: custom pricing.

One caveat: Make's pricing page shows a "Save 15%" badge on these prices, and Make's own blog quotes $12, $21 and $38 a month for Core, Pro and Teams at the same 10,000-credit tier. I could not read the page's billing toggle, so treat $9 as the lowest published figure and expect monthly billing to cost more. Any Make estimate written before the switch to credits is no longer comparable.

What One Workflow Costs at 500 to 20,000 Runs a Month

Headline prices hide the billing unit. A Zapier task is one action step, a Make credit is consumed per module, and an n8n execution is one whole workflow run however many nodes it has. So I priced one example workflow, a trigger plus five actions, across run counts. I wrote a small script from the published tiers (the Zapier figures come from the plan data embedded in zapier.com/pricing) and ran it on 17 November 2026 with Python 3.12.3. Five unit tests on the tier boundaries pass.

Assumptions. Zapier counts 5 tasks per run: the five actions at one task each, the trigger at zero. Zapier's pricing page says every step uses tasks and that AI model tier, code runtime and connector type can raise the count, so a real Zap may land in a higher tier. Make counts 6 credits per run (trigger plus five actions, my assumption). n8n counts 1 execution per run. All three use annual-billing rates, and Zapier's monthly-billed price is shown separately.

Rerunning the script for a workflow with two actions (2 Zapier tasks and 3 Make credits per run) gives Zapier $129 a month at 5,000 runs and $189 at 10,000 runs, against €50 for n8n Cloud at both, so Zapier's gap narrows but does not close.

Which Platform Should You Choose?

Choose n8n if...

  • You are building complex, multi-step workflows with conditional logic.
  • You need AI automation (LLM chains, AI agents, custom AI pipelines).
  • You want to control costs at volume, or keep data on your own servers.
  • Your team has at least one person comfortable with technical concepts and with running a server, or you are happy to pay for Cloud.

Choose Zapier if...

  • You need simple, straightforward automations of a few steps.
  • Your team is non-technical and needs the fastest possible setup.
  • You rely on niche apps that only Zapier supports.
  • You run low volumes and value setup speed over long-term cost.

Choose Make if...

  • You want a visual workflow builder with more flexibility than Zapier.
  • Budget matters, but you do not want to self-host.
  • Your scenarios are moderately complex and you are comfortable counting credits.

How I Would Decide

Start from the workflow, not the brand. Count the steps in your most common workflow, estimate runs per month, and read the matching row of the cost table. If the answer is a few steps and a few hundred runs, price barely matters, so take the tool your team will actually use. Once workflows have many steps or run thousands of times a month, the billing unit starts to decide the bill.

A disclosure: I write n8n tutorials and a self-hosting guide for it, so I lean toward n8n for workflows that mix data handling, branching and AI calls. That lean is a judgment, not a measured result, and this page does not rest on any client project. Zapier is the right answer for a quick connection between two apps with no appetite for infrastructure. Make is a good fit for visual design on a small budget. If you are unsure, read the FAQ or book a call.

Frequently Asked Questions

Is n8n really free?

Yes, if you self-host. The n8n Community Edition is free to self-host with no per-execution fee, and your only cost is the server. If you would rather not run infrastructure, n8n Cloud Starter is €20/month billed annually for 2,500 executions.

Can I migrate from Zapier to n8n?

Yes, but there is no one-click migration tool. You rebuild each Zap as an n8n workflow. The Zapier to n8n migration guide covers the order to do it in. For complex multi-step Zaps, an automation expert can migrate and often improve the workflows in the same pass.

Which platform is best for AI automation workflows?

n8n is my pick. It has an AI Agent node, MCP client and server support, JavaScript and Python code steps and direct HTTP calls to any model API, so you can build AI agents that plan and use tools. Make has its own AI Agents and AI modules, and Zapier offers Agents and an MCP server for simpler AI tasks.

Which is cheapest at 1,000 runs a month?

For a workflow of a trigger plus five actions, Make Core at $9 a month is cheapest on paper, then n8n Cloud Starter at €20, then Zapier Professional at $89 on annual billing. Self-hosted n8n costs only the server. Change the step count and the order can change, so use the table above as a starting point.

Does Make still have separate Core, Pro and Teams plans?

Yes. Make's pricing page lists Free, Core, Pro, Teams and Enterprise. Since the move from operations to credits, each tier is priced by credits per month: Core $9, Pro $16 and Teams $29 at the 10,000-credit tier on the pricing page.
